API de Datos de CKAN

Accede a los datos del recurso a través de una API web con potentes opciones de consulta. Más información en la documentación principal de la API de Datos y DataStore de CKAN.

Endpoints »

La API de Datos se puede acceder mediante las siguientes acciones de la API de acciones de CKAN.

Consulta https://datos.madrid.es/api/3/action/datastore_search

Consultando »

Ejemplo de consulta (primeros 5 resultados)

https://datos.madrid.es/api/3/action/datastore_search?resource_id=218228-1-ser-calles-csv&limit=5

Ejemplo de consulta (resultados que contienen 'jones')

https://datos.madrid.es/api/3/action/datastore_search?resource_id=218228-1-ser-calles-csv&q=jones

Ejemplo: Javascript »

Filtrar por valor de campo:

Una simple petición ajax (JSONP) a la API de datos usando jQuery.

        var data = {
          resource_id: '218228-1-ser-calles-csv', // the resource id
          limit: 5, // get 5 results
          q: 'jones' // query for 'jones'
        };
        $.ajax({
          url: 'https://datos.madrid.es/api/3/action/datastore_search',
          data: data,
          dataType: 'jsonp',
          success: function(data) {
            alert('Total results found: ' + data.result.total)
          }
        });

Ejemplo: Python »

      import urllib
      url = 'https://datos.madrid.es/api/3/action/datastore_search?resource_id=218228-1-ser-calles-csv&limit=5&q=title:jones'  
      fileobj = urllib.urlopen(url)
      print fileobj.read()
